# بسته فرم‌های تشخیص و توسعه کسب‌وکار — پیشرو مبتکر قرن

هفت فرم فارسی راست‌چین با برند **پیشرو مبتکر قرن** در هدر، برای جمع‌آوری اطلاعات از صاحب کسب‌وکار (بدون نیاز به تخصص)، جهت تحلیل مدل درآمدی، بازار جدید، اتوماسیون و توسعه آنلاین.

## فهرست فرم‌ها

| کد | فایل PDF | موضوع |
|---|---|---|
| F01 | `pdf/F01-شناسنامه-کسب-وکار.pdf` | شناسنامه کسب‌وکار |
| F02 | `pdf/F02-مدل-درآمد-و-مالی.pdf` | مدل درآمد و مالی |
| F03 | `pdf/F03-مشتری-و-بازار.pdf` | مشتری و بازارهای جدید |
| F04 | `pdf/F04-فروش-و-بازاریابی.pdf` | فروش و بازاریابی |
| F05 | `pdf/F05-عملیات-و-اتوماسیون.pdf` | عملیات و اتوماسیون |
| F06 | `pdf/F06-حضور-آنلاین-و-دیجیتال.pdf` | حضور آنلاین و دیجیتال |
| F07 | `pdf/F07-تیم-مشکلات-و-اولویت‌ها.pdf` | تیم، مشکلات و اولویت‌ها |

## کد رهگیری

روی هدر هر فرم باکس `BG-________` قرار دارد. هنگام تحویل به مشتری، یک کد یکسان (مثلاً `BG-1404-0042`) روی همه فرم‌های همان پرونده بنویسید تا تحلیل‌ها قابل اتصال باشند.

## بازتولید PDF

```bash
cd business-forms
chmod +x generate-pdfs.sh
./generate-pdfs.sh
```

نیازمند Google Chrome یا Chromium است. خروجی در پوشه `pdf/` نوشته می‌شود.

## چاپ

فرمت A4، مناسب پر کردن دستی با خودکار. ترجیحاً دورو چاپ نکنید تا فضای نوشتن کافی بماند.
